# CharlyMC

静态中文整合包展示网站，无构建依赖。部署目录为 `dist/`。

## 预览

在此目录运行 `python3 -m http.server 4173 --directory dist`，打开 http://localhost:4173 。

## 更新内容

- `dist/index.html`：最新版本、文件大小、更新说明、安装指南、服务器信息。
- `dist/app.js`：历史版本列表、复制服务器地址功能、Canvas 方块景观。
- `dist/style.css`：响应式布局和视觉样式。

当前下载入口指向原飞书文档，未迁移附件。准备好自己的文件托管地址后，可替换最新版本及历史版本的链接。服务器区域为静态连接信息，不提供在线状态检测。

网页可部署到任意静态网站托管服务。外部 Google Fonts 不可用时会自动使用系统中文字体。
